Primer núcleo Android real de ÓRBITA. **No es Alfa 0.1 completa.**

Incluye HOME, bienvenida, catálogo de apps del perfil personal, búsqueda local, escritorio de cinco columnas, fijar/quitar accesos y dock de hasta cinco favoritos, DataStore y tema automático Essential. Sin cuentas, red ni permisos masivos.

El flujo publica este APK solo tras superar pruebas unitarias, Android lint, compilación y un smoke de interfaz en emuladores Android API 29 y 35. Consulta los informes del workflow asociado al commit. Esto no certifica todavía TalkBack, rendimiento en hardware, reinicio de dispositivo ni toda la matriz P0.

Pendientes: páginas y mover accesos, carpetas, gestos, recuperación explícita de datos, validación de fuente ampliada y TalkBack. Liquid, Motion Engine avanzado, widgets y Atelier quedan para próximas fases.

Desde tu teléfono, descarga **ORBITA-0.1.0-dev.1.apk** en Assets e instálalo. En los ajustes Android elige ÓRBITA como aplicación de inicio. Puedes volver al launcher anterior desde esos mismos ajustes. Android mínimo 8 (API 26); pruebas instrumentadas de este incremento en API 29/35.

APK de depuración, no de producción. Esta primera versión no tiene todavía una política de firma persistente para futuras actualizaciones; el workflow evita reemplazarla automáticamente por un APK firmado con otra clave. No desinstales una versión con datos importantes para instalar otra sin respaldo. SHA256SUMS.txt permite comprobar integridad.
