# ÓRBITA 0.2.0-alpha.1 · AMOLED y personalización inicial

- Tema AMOLED con fondo #000000, texto, búsqueda y monogramas blancos.
- Temas Essential (automático/claro/oscuro), Pixel inspirado y paleta Liquid inicial.
- Tamaño de iconos de 32–64 dp, etiquetas opcionales y monogramas blancos.
- Reloj integrado con tamaño de 32–72 sp, fecha opcional y formato horario del sistema.
- Barra de búsqueda de aplicaciones opcional en el escritorio.
- Perfiles de movimiento suave, equilibrado y con peso; presión con resorte y transición vertical del cajón. Respeta movimiento reducido.
- Frecuencia preferida Automática o modos compatibles hasta 144 Hz en la resolución actual. Android, el fabricante, batería y pantalla deciden el modo efectivo. 0 es Automática, no 0 Hz físicos.
- Preferencias persistentes y respaldo v2 compatible con respaldo v1.

## Alcance real de esta alfa

No incluye todavía widgets Android de terceros, editor libre por elemento, paquetes de iconos, importación de imágenes ni física de arrastre. El reloj es un componente propio de ÓRBITA, por ahora en una posición fija. Liquid es una paleta inicial sin refracción ni desenfoque real. Pixel es una inspiración visual; la identidad de ÓRBITA permanece propia.

El ajuste de frecuencia afecta únicamente la ventana del launcher. Las animaciones de Recientes, bloqueo y otras aplicaciones pertenecen a Android.

La verificación automática no sustituye pruebas de rendimiento con teléfonos reales de 60/90/120/144 Hz, TalkBack y fabricantes. No se promete un FPS constante.
