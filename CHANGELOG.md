# Cambios

## 0.1.0-alpha.1 — 12 de octubre de 2026

Páginas/slots/dock, carpetas con orden manual, movimiento/intercambio/deshacer, gestos con alternativas, Essential Auto/Claro/Oscuro y preferencias con vista previa. Persistencia versionada, migración con IDs estables, respaldo válido, archivo de originales corruptos, exportación y recuperación explícita. Núcleo compartido entre HOME y entrada ordinaria; búsqueda/serialización fuera del hilo UI y apertura de componentes durante carga.

Compilación, 12 pruebas unitarias, lint y 40 ejecuciones de aceptación entre API 26/29/33/35 aprobadas. APK debug con firma persistente publicada tras CI. TalkBack hablado y pruebas físicas permanecen pendientes; no se declara P0 totalmente certificado.

Dev.1 requiere desinstalación única para cambiar de firma. Widgets, Liquid, Atelier y física avanzada no incluidos.
